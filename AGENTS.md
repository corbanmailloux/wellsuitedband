# AGENTS.md

Static-export Next.js site for wellsuitedband.com (App Router, Tailwind v4, TypeScript).

## Commands

- `npm run dev` — dev server (also `make dev` / `make install`)
- `npm run build` — production build; there is no server, see `output: 'export'` in `next.config.mjs`
- `npm run lint` — ESLint (flat config in `eslint.config.mjs`); no typecheck/test scripts exist — use `npx tsc --noEmit` for types, no test suite at all

## Gotchas

- **Static export**: `next.config.mjs` uses `output: 'export'` with `images.unoptimized: true`. No server features (no API routes, no SSR-only APIs). Build outputs to `/out`.
- **Images must be pre-optimized** and committed: code references `/images/optimized/*` (mostly AVIF), which is generated by `npm run optimize-images` from originals in `public/images/`. Raw sources must stay in `public/images/` (not `optimized/`) so the script can regenerate.
- Turbopack is on by default in Next 16; `turbopack.root` is pinned in `next.config.mjs`.
- **TypeScript is deliberately held at 6.x** (`^6.0.3`); `ncu` will keep proposing `^7.0.2` — do not bump it. TS 7 is the Go rewrite and ships **no compiler API until 7.1**, so `typescript-eslint` refuses to load: `npm run lint` dies with `Error: typescript-eslint does not support TS 7.0.` at config-import time (not a rule error — the whole run aborts). Its `typescript` peer range is also `<6.1.0`. Verified 2026-10-06: with TS 7 installed via `npm i --no-save typescript@7.0.2`, `npx tsc --noEmit` and `next build` both still pass, but `npm run lint` fails outright — lint is the blocker, not types. Tracking: typescript-eslint/typescript-eslint#10940. **Revisit when typescript-eslint declares `typescript: >=7.1`.** Alternate path if TS 7 is wanted sooner: the TS 7.0 announcement documents a side-by-side setup (`"typescript": "npm:@typescript/typescript6@^6"` plus a separate `@typescript/native` alias), which keeps `typescript-eslint` on the 6.0 API while `npx tsc` runs 7 — but note TS 7 also defaults `types` to `[]`, so add an explicit `"types"` array to `tsconfig.json` if `@types/*` globals stop resolving.

## Layout

- `src/app/` — pages (`/`, `/about`), `layout.tsx`, `robots.ts`, `sitemap.ts`, `not-found.tsx`
